# Ankit Pal — Manga Portfolio

A manga-style developer portfolio: a single-page "chapter" experience with a Three.js RAG-lattice hero, GSAP page-turn scene transitions, and chapter-wise sections — Character File, Power Levels, Special Moves, Quest Log, Research Scroll, Hall of Fame, Experience and Contact.

**Live:** https://ankit500ak.github.io/manga-portfolio/

Built as one self-contained `index.html` (Three.js + GSAP via CDN).
